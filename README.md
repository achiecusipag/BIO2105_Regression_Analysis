# BIO2105_Regression_Analysis

1. Project Overview

This project focuses on correlation and simple linear regression analysis using R and RStudio. It aims to examine relationships between variables, perform statistical computations, create visualizations, and evaluate regression model assumptions.

2. Research Objectives

The objectives of this activity are to:

Identify predictor and response variables.

Calculate and interpret Pearson's correlation coefficient.

Understand linear transformation invariance.

Perform simple linear regression analysis.

Interpret regression coefficients and the coefficient of determination (R²).

Conduct hypothesis testing and calculate confidence and prediction intervals.

Generate and interpret ANOVA tables.

Evaluate regression assumptions using residual diagnostic plots.

3. Datasets Used

This project uses two built-in R datasets:

Dataset 1: trees

The trees dataset contains measurements of 31 felled black cherry trees. It includes:

Girth – trunk diameter in inches.

Height – tree height in feet.

Volume – timber volume in cubic feet.

The analysis focuses on predicting timber Volume using Girth.

Dataset 2: women

The women dataset contains average height and weight measurements of 15 American women aged 30–39.

Height – measured in inches.

Weight – measured in pounds.

The analysis focuses on predicting Weight using Height and evaluating the assumptions of the linear regression model.

4. Repository Contents

This repository contains the following files:

README.md – Provides the project overview, objectives, datasets, and instructions for reproducing the analysis.

BIO2105_Regression_Analysis.R – Contains the executable R code for the statistical computations and visualizations.

BIO2105_Regression_Analysis.Rmd – Contains the R Markdown report, including code, results, and written interpretations.

BIO2105_Regression_Analysis.html – Contains the knitted output of the R Markdown report.

5. Instructions to Reproduce the Analysis

To reproduce the results of this project:

Install and open RStudio.

Download or clone this GitHub repository.

Open BIO2105_Regression_Analysis.R in RStudio.

Click the Source button to execute the R script.

Check the Console and Plots panel for the statistical results and visualizations.

Open BIO2105_Regression_Analysis.Rmd in RStudio.

Run the code chunks and review the written interpretations.

Click Knit to generate the HTML report.

Check that all tables, results, and diagnostic plots are displayed correctly.

The analysis uses built-in R datasets (trees and women), so no external data files are required.
